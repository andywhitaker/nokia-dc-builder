# Nokia Data Center Rack Builder

A web-based interactive tool to design, arrange, and wire data center racks populated with Nokia switches in 3D.

## Overview

Nokia Data Center Rack Builder allows network architects and engineers to visually plan data center equipment layouts, scale cabinet capacities, and simulate inter-rack patch cabling in a real-time 3D environment.

## Key Features

- **3D Rack Visualization**: Preview server cabinets, switch faceplates, and elevation slots in interactive 3D.
- **Nokia Hardware Line**: Populate racks with Nokia 7220 IXR & 7730 SXR series switches running SR Linux.
- **Multi-Rack Row Cabling**: Place cabinets side-by-side to wire 3D patch cables between device ports.
- **Dynamic Rack Capacity**: Scale cabinet U heights with automatic equipment position adjustment.
- **Layout Persistence & Export**: Automatically save progress locally, export/import JSON designs, and generate Bill of Materials (BOM) specs.
